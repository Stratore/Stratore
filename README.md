## Featured Projects

### [3D Portfolio](https://github.com/Stratore/portfolio)
Interactive portfolio rendered as a 3D network graph (projects, technologies, skills as connected nodes), with a text-based fallback for accessibility and SEO. Built with Next.js and React Three Fiber, directing AI tooling (Claude Code) feature by feature rather than letting it run unsupervised.

![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?style=flat-square&logo=typescript&logoColor=white)
![Next.js](https://img.shields.io/badge/Next.js-000000?style=flat-square&logo=nextdotjs&logoColor=white)
![Three.js](https://img.shields.io/badge/Three.js-000000?style=flat-square&logo=threedotjs&logoColor=white)

### [Klass.cpp](https://github.com/Stratore/Klass)
Desktop student management app in C++/Qt: student records (identity, contact info, photo, class group) and attendance tracking with justified/unjustified absences. Data is persisted to flat JSON/XML files, no database layer.

![C++](https://img.shields.io/badge/C%2B%2B-00599C?style=flat-square&logo=cplusplus&logoColor=white)
![Qt](https://img.shields.io/badge/Qt-41CD52?style=flat-square&logo=qt&logoColor=white)

### [GpierreS](https://github.com/Stratore/gps)
Interactive GPS application in C++/Qt built from two provided CSV datasets (100 cities and pairwise travel times). Computes shortest paths with Floyd-Warshall, supports adding intermediate stops, and enriches the selected city with live weather data from the Météo France API.

![C++](https://img.shields.io/badge/C%2B%2B-00599C?style=flat-square&logo=cplusplus&logoColor=white)
![Qt](https://img.shields.io/badge/Qt-41CD52?style=flat-square&logo=qt&logoColor=white)
