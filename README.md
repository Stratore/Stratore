## Projects

### [Panel](https://github.com/Stratore/panel)
Self-hosted tech & cyber watch dashboard: IT news front page, CVE and exploited
vulnerability monitoring, data breaches and releases, alerts to Discord / Telegram.
TypeScript monorepo, SSRF-safe fetching, strict CSP with Trusted Types, Docker.

### [Portfolio 3D](https://pierre-puget.fr)
My portfolio as a solar system: projects are planets, technologies and skills are
moons and asteroid belts. Next.js, React Three Fiber, hand-written GLSL shaders,
hardened security headers, with a plain-text fallback view.

### [Still Out There](https://github.com/Stratore/Still-Out-There)
Check whether an e-mail address appears in known data breaches, through the
XposedOrNot API. Object-oriented JavaScript, webpack, local caching of the catalogue.

### [GpierreS](https://github.com/Stratore/GPS)
Desktop GPS in C++ / Qt: shortest paths between France's 100 largest cities with
Floyd-Warshall, unlimited stops, travel-time matrix and live weather.

### [Klass](https://github.com/Stratore/Klass)
Student management app in C++ / Qt (team project): student records, photos, absences,
data kept in sync in JSON and XML, French translation.

### [Facture](https://github.com/Stratore/Facture)
Gas billing mock-up in C++ / Qt: consumption and price from meter readings, per-session
and admin dashboards.

### [Digital Imagery](https://github.com/Stratore/Digital_Imagery)
Image processing library in C++ with no dependencies: PGM, PPM and TGA (with RLE),
nearest-neighbour and bilinear scaling. Work in progress.
